# Assessment

Assessment here measures **decisions**, not recall. All items are scenario-based: each presents a realistic situation at Northwind Logistics (or a school-equivalent situation) and asks what the learner would do.

| Assessment | Tracks | Format |
|---|---|---|
| [Scenario quiz](scenario-quiz/index.html) | Workplace | 12 items in the browser; feedback on every option; results by objective; nothing is stored or sent anywhere |
| [Performance task](performance-task.html) | Both | Correct a flawed "AI-generated" document (constructed for teaching purposes) and produce a verification log |
| [Rubric](rubric.html) | Both | 4 criteria × 4 levels: accuracy checking, data judgment, bias recognition, justification |

The [alignment matrix](../design/alignment-matrix.html) maps every objective to the items and tasks that assess it. Item-level analysis of the quiz (which options attract mistakes) is part of the evaluation plan; see [evaluation methods](../design/evaluation-report.html).
