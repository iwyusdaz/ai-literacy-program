# Alignment matrix

Every objective → content → practice → assessment → framework. "Quiz Q#" refers to the [scenario quiz items](../assessment/scenario-quiz/index.html) (see `items.json` `objective` fields for the machine-readable mapping). AILit competence names use the **final** framework (see [framework mapping](framework-mapping.html)).

*Last reviewed: 2026-10-25*
