# School track

Four lessons of 50 minutes for students aged 14–16 (Grade 9–10 / Year 10–11), designed for a **non-specialist teacher**. No prerequisites, no installs, and every lesson has an unplugged fallback if devices are unavailable.

| # | Lesson | Core question | Main activity |
|---|---|---|---|
| 1 | [How AI makes text](lesson-1-how-ai-makes-text.html) | Does a chatbot "know" things? | [Next-word interactive](../interactives/next-word/index.html) + human predictor game |
| 2 | [When AI gets it wrong](lesson-2-when-ai-gets-it-wrong.html) | Why are wrong answers so convincing? | Fact-check challenge in pairs |
| 3 | [Bias and fairness](lesson-3-bias-and-fairness.html) | Whose perspective is missing? | Compare outputs; discuss training data |
| 4 | [Using AI to learn, not to skip](lesson-4-using-ai-to-learn-not-to-skip.html) | When does AI help my learning? | Design personal AI-use rules; project briefing |

**Start here if you teach this unit:** [Teacher guide](teacher-guide.html) — unit overview, timings, script prompts, misconceptions to watch for, differentiation, answer keys, and how to run the unit with no devices.

Handouts (printable): [Fact-check worksheet](handouts/fact-check-worksheet.html), [Next-word recording sheet](handouts/next-word-recording-sheet.html), [My AI-use rules](handouts/my-ai-use-rules.html), [Project planner](handouts/project-planner.html).

The unit ends with a [final project](final-project.html) and the [performance task + rubric](../assessment/rubric.html) used for both tracks.
